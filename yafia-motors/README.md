# יפיע מוטורס | يافا موتورز

אתר תדמית מקומי בעברית ובערבית בלבד. ללא כניסה ל־ChatGPT, ממשק ניהול, חשבונות משתמשים או מסד נתונים. כל התמונות והגופנים שמורים בקובצי האתר.

## הפעלה

לחיצה כפולה על `START-LOCAL.cmd` בתוך תיקיית הפרויקט בונה את האתר, מפעילה שרת מקומי ופותחת את הדפדפן. נדרשת Node.js 26. אין תלויות להתקנה.

```sh
npm run build
npm run check
npm run check:content
npm run check:seo
npm start
```

עברית: http://localhost:4173/he/

ערבית: http://localhost:4173/ar/

להפעלה מתוך תיקיית הפרויקט: `node launch-local.mjs`. אפשר לסגור את חלון ההפעלה; השרת ממשיך לפעול ברקע.

## תוכן

- דף בית, שירותים, אודות, צוות, אזור שירות, מגזין, קשר ופרטיות.
- שבעה דפי שירות: רכב אמריקאי, אבחון, טיפולים, מנועים, גירים, בלמים ומכונאות, ומערכת קירור ומים.
- שלושה מאמרים מקוריים בכל שפה, עם קישור למקור היצרן הרלוונטי.
- תוכן מקצועי מורחב לכל שבעת השירותים ולשלושת המאמרים: הגדרת הנושא, בדיקות, החלפות לפי צורך, טבלאות, שלבי עבודה, בדיקות סיום ושאלות נפוצות. אין מרווחי טיפול או מפרטי נוזלים אחידים לכל הדגמים.
- 36 דפים בנתיבי שפה, דף כניסה ראשי ועמוד 404.
- כותרות ותיאורים נפרדים, canonical, hreflang, Open Graph, נתונים מובנים ומפת אתר.
- התאמה לנייד, ניווט מקלדת, תמיכה בהפחתת תנועה, תפריט נייד, גלריה ושאלות נפוצות.

הטופס מכין הודעה בוואטסאפ; הגולש שולח בעצמו. מידע אינו נשמר בשרת האתר.

## נתוני העסק

הטלפון 050-6520081 והכתובת "יפיע, כביש ראשי" מופיעים בכרטיס העסק שסופק ואותרו גם ברישום ציבורי. שעות פעילות ונתוני ותק מספריים לא הומצאו. הגעה בתיאום מראש. אין טענה להרשאת יבואן, דירוג לקוחות או תנאי אחריות קבועים.

צילומי המוסך והצוות נוצרו להמחשה ואינם מציגים את העובדים או המקום בפועל. מופיע סימון באתר הדוגמה. לקראת שימוש מסחרי יש להתאים תמונות צוות, שעות, פרטי רישוי והסמכה, כתובת מדויקת ותנאי העסק.

## מחקר תוכן

התוכן מקורי, נכתב בהשראת תחומי השירות בענף ולא הועתק מאתר מתחרה.

- [רישום יפיע מוטורס במאגר מוסכים ביפיע](https://cars.sites.compee.co.il/garages/499) — התאמה לשם, לטלפון ולכביש הראשי.
- [פיני שירותי רכב — סדנה לאמריקאיות](https://american-garage.co.il/) — מחקר על מבנה שירותים והתמחות במותגים אמריקאיים; אינו מקור לנתונים על יפיע מוטורס.
- [Chevrolet — Maintenance schedule](https://www.chevrolet.com/support/vehicle/maintenance/schedule).
- [Ford — Transmission maintenance](https://www.ford.co.uk/support/how-tos/owner-resources/vehicle-maintenance/what-maintenance-is-required-on-the-transmission).
- [Chevrolet — Engine oil](https://www.chevrolet.com/support/vehicle/under-the-hood/engine-oil).

צילומי השירותים החדשים הוכנו לפי נושאי הדפים: מנוע תלוי במנוף מעל תא מנוע, גיר מפורק על מגבה, מערכת קירור עם רדיאטור ובדיקת לחץ, דיסק וקליפר בלם, טיפול שמן ומסננים, וסורק מחובר לשקע האבחון. למאמר על התראת שמן הוכנה תמונת לוח מחוונים עם נורת שמן אדומה. מיפוי התמונות ותיאוריהן בעברית ובערבית נמצא ב־media.mjs ומשותף לכל הכרטיסים, דפי השירות, הגלריה והמאמרים.

הגופנים Heebo, Noto Sans Arabic ו־Oswald מאוחסנים מקומית. פרטי הבסיס נמצאים ב־build.mjs; תוכן השירותים והמאמרים ב־content.mjs, ב־arabic.mjs וב־media.mjs. ב־editorial.mjs נמצאים התכנים הנפרדים של הבית, האודות, הצוות, אזור השירות, ההכנה לכל שירות והשאלות הנפוצות לפי הקשר. התוכן המקצועי המורחב נמצא ב־professional-he.mjs, ב־professional-ar.mjs וב־professional-articles.mjs. מקורות המקצוע נרשמו ב־professional.mjs. לכל דף מוגדרים כותרת ותיאור חיפוש נפרדים ב־seo.mjs.

`npm run check:content` סורק את התוכן המרכזי ב־36 דפי השפה ומזהה פסקאות זהות באורך 70 תווים ומעלה בתוך דף או בין דפים. כרטיסי ניווט, באנרים משותפים ופרטי גילוי קבועים מוחרגים מהבדיקה. הבדיקה אינה מחליפה קריאה ועריכה של התוכן.

`npm run check:seo` בודק כותרות ותיאורי מטא ייחודיים, H1 יחיד, H2, קישורי תוכן עניינים, תיאורי alt, נתוני Service/Article, כתובות canonical והתאמת שפת התוכן. לוגואים דקורטיביים ותמונת דיאלוג נסתרת יכולים לכלול alt ריק במכוון. מפת האתר כוללת את 36 כתובות הדפים הקנוניות; דף הכניסה הראשי מצביע ב־canonical על הבית בעברית.

מקורות ההרחבה כוללים תיעוד של Chevrolet ו־Ford על תחזוקה, Bosch על אבחון, ZF על תיבות הילוכים, Brembo על בדיקות בלמים, Gates ו־Valeo על קירור, ו־Motorservice על התקנת מנוע והפעלה ראשונית. קישורים למקורות המתאימים מוצגים גם בדפים עצמם. הוראות של דגם או מכלול מסוים אינן מוצגות ככלל לכל כלי הרכב, ואין התחייבות שכל בדיקה אפשרית נדרשת בכל ביקור.

## פרסום וקידום

זו גרסה מקומית. אין צורך בשירות אחסון או בחשבון כלשהו לצפייה. כתובת הבסיס לבנייה היא http://localhost:4173. אם מעלים בעתיד לדומיין, מגדירים את משתנה הסביבה SITE_ORIGIN לדומיין ומריצים `npm run build`; הכותרות, כתובות השפה, הנתונים המובנים ומפת האתר נבנים בהתאם. אין התחייבות לדירוג בחיפוש.

### GitHub ו־Vercel

קוד האתר והנכסים נמצאים בתיקייה `yafia-motors` במאגר. גיבויי ZIP, מטמון, פרופיל דפדפן ותוצרי בדיקה נשארים מקומיים ומוחרגים מ־Git. הקבצים ב־`dist/assets` הם תמונות, גופנים, CSS ו־JavaScript נדרשים; דפי ה־HTML נוצרים בפקודת הבנייה.

בפרויקט Vercel נפרד בשם `yafia-motors-garage`, בוחרים Root Directory: `yafia-motors`, Framework Preset: Other, Node.js: 26.x, Build Command: `npm run build`, Output Directory: `dist`. קובץ `vercel.json` מגדיר הפניה קבועה מהשורש אל `/he/` וכתובות עם לוכסן סופי. לא נדרש שרת Node בפעולת האתר לאחר הבנייה.

כתובת היעד לפרסום: `https://yafia-motors.mybizsite.co`. יש להגדיר SITE_ORIGIN לכתובת זו בסביבת Production של Vercel. הבנייה ב־Vercel משתמשת בכתובת זו כברירת מחדל; בנייה מקומית רגילה נשארת ב־localhost.

בדיקת גרסת פרסום מקומית:

```sh
npm run build:production
npm run check
npm run check:content
npm run check:seo
npm run check:production
```

לאחר הוספת תת־הדומיין לפרויקט Vercel, יוצרים אצל ספק ה־DNS רשומת CNAME בשם `yafia-motors` עם היעד המדויק שיופיע בפרויקט. אין להעתיק ערך מפרויקט האתר הראשי או להחליף את רשומות הדומיין הראשי והדואר. פרסום הושלם רק לאחר אימות הדומיין, HTTPS וגישה ציבורית ללא התחברות.
